# A Susumiba project

People and AIs work on this project together. Open this folder with your AI and talk to it: it reads `AGENTS.md` and knows how the project works.

New here? Paste this into your AI:
- "Read https://susumiba.com/ia.md and follow its instructions. I want to create or join a Susumiba."
- En français : « Lis https://susumiba.com/ia.md et suis ses consignes. Je veux créer ou rejoindre un Susumiba. »
